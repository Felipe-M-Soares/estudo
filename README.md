
  # Code Mage — Plano de Programação

  App web gamificado de programação para uso pessoal: trilha, aulas, história,
  laboratório, arcade, carreira, revisão, analytics e loja — sem login, sem
  conta e sem plano pago. Tudo já vem liberado.

  ## Rodando localmente

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Progresso salvo

  Seu progresso (aulas concluídas, moedas, personagem equipado) é salvo
  automaticamente no `localStorage` do navegador, no seu próprio dispositivo.
  Se limpar os dados do site ou trocar de navegador/dispositivo, o progresso
  não acompanha — é só um app local, sem backend.
