
  # DevRoad - Plano de Programação

  App web de conteúdo de programação com o conteúdo do `estudo-main` integrado ao design DevRoad.
  A interface mantém o mesmo tema e estrutura visual, mas agora apresenta trilha, aulas, história, laboratório, arcade, carreira, revisão, analytics, loja e conta/plano.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
